# Product Recommendation Engine Notebook

Download this complete beginner-friendly package to build a product
recommendation engine on your own computer.

The example uses a generic online shop dataset with customer-product events such
as views, clicks, basket adds, purchases, and reviews. The notebook converts
these events into an implicit-feedback user-item matrix, applies BM25
re-weighting, trains an Alternating Least Squares matrix-factorization model,
and uses Optuna to search for stronger hyperparameters.

The package includes:

- a sample interaction CSV file
- a sample product catalog CSV file
- a Jupyter notebook with step-by-step explanations
- reusable Python code
- beginner setup instructions

Download the ZIP file:

`Product_Recommendation_Engine_Package.zip`

After downloading, unzip the folder before opening the notebook.
